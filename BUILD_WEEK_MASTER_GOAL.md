## Spatial Index Finder contract

The Spatial Index Finder is a deterministic local record-navigation workspace. It can:

- search rooms, assets, samples, equipment, cabinets, drawers, shelves, and stored notes;
- match multi-term search text to canonical indexed records;
- select and focus exact items in 2D and 3D;
- expose location, ownership, maintenance, and storage evidence only from stored project data;
- preserve exact room context, evidence photography, canonical codes, QR identity, and editor deep links.

Results never infer or invent missing inventory. Placement checks remain a separate direct Warnings workflow in the Layout Editor and never imply safety certification.
