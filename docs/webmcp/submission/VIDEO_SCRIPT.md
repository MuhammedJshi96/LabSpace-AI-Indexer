## Recording notes

- Use one continuous 1920×1080 capture where possible; crop browser chrome only if the URL/tool evidence remains credible.
- Record voice live with Windows Snipping Tool or add the same narration afterward—no music is needed.
- Keep the final cut below 3:00 and leave 10–15 seconds of editing margin.
- Do not show local file paths, private laboratory photographs, DevTools errors, or unrelated tabs.
- If the free host cold-starts, wake it before recording; do not include the loading delay.
